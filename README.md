# SingleKey Code Catcher
A FireFox Add-on for Extended Bosch thermostat ha-pro (CT200 cloud) integrations in HomeAssistant. This Add-on will help you extract the needed key for your installation.

This is the HA Integration: https://github.com/CaseyRo/ha_bosch

Also works for: https://github.com/serbanb11/bosch-homecom-hass

Follow the instructions in HA. It tells you to login to your SingleKey ID. After login it will not redirect the site, a "Continue" will pop-up. Press on that and then check on this Add-on, you will now have the needed key to continue your setup/re-login.


## How to install the Add-on

Start with downloading the latest [release](https://github.com/Tozzi89/SingleKey-Code-Catcher/releases). 
> [!NOTE]
> _Only the `singlekey-addon.xpi` file is needed_

### Method 1

Drag-n-drop the `singlekey-addon.xpi` into a Firefox window, it should ask you to confirm the installation, just follow the steps in the browser and you should be good to go.

### Method 2

* Open Firefox and go to `about:addons` in the address bar.
* Click the gear icon near the top right of the page.
* Select `Install Add-on From File...` from the menu.
* Browse to the `singlekey-addon.xpi` you saved earlier and click `Open`.
* Click `Add` to confirm.
